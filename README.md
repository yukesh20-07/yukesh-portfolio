# Yukesh M — Portfolio Website

A responsive portfolio built with plain HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, typography, and visual styling
- `script.js` — mobile navigation, current year, and contact form behavior
- `assets/yukesh-photo.jpeg` — supplied profile photo

## Edit your details
Search `index.html` to update your introduction, education, skills, links, or contact information.

## Add projects
The Projects section intentionally does not claim any completed projects. Replace the empty-state block with project cards when you have real work to showcase. Keep the comment in that section as a reminder.

## Contact form note
The form validates the required fields and opens the visitor's default email app with a prefilled message addressed to `yukeshyuva20@gmail.com`. It does not send or store messages on a server. For direct submissions without an email app, connect a form backend or form service and update `script.js`.

## Publish
Upload the contents of this folder to any static hosting provider (for example, GitHub Pages, Netlify, or Vercel). Keep the `assets` folder beside `index.html`.
